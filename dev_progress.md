## Decisions Locked

| Decision | Value | Rationale |
|---|---|---|
| Garmin mode | **Virtual Run** (`Sensors > Virtual Run`) | Only mode that broadcasts HR (`0x180D`) + Running Speed & Cadence (`0x1814`) for pace/cadence/stride/distance. Broadcast HR alone gives only HR. |
| OS | **Windows 10/11 only** | User requirement; Web Bluetooth via Chrome/Edge on Windows. |
| Pace unit | **min/km primary**, km/h secondary toggle | User preference. |
| Distance source | **Garmin RSC total distance** (`0x1814` distance field) | No manual treadmill correction in MVP. |
| HR zones | **Garmin defaults** (220-age, 5 zones) | Configurable later. |
| FIT target | **Garmin Connect only** | Strava later. |
| Offline | **PWA, nice-to-have** | Works on `localhost` without internet after first load. |
| Always-on-top | **Not needed in MVP** | Deferred. |
| Distribution | **Hybrid: Web App (PWA) first ? Tauri portable .exe** | Fastest to validate via browser, then wrap same codebase as portable exe. |

### Localhost Note

Web Bluetooth requires a [Secure Context](https://developer.mozilla.org/en-US/docs/Web/Security/Secure_Contexts). `http://localhost` and `http://127.0.0.1` **are secure** � no HTTPS needed. `http://192.168.x.x` is **not** secure and will fail. Tauri wrapper has no such restriction.

- FIT fields: speed `m/s*1000`, distance `m*100`, HR/cadence as `uint8`/`uint16`, timestamps as FIT epoch seconds.
